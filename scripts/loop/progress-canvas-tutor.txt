# Loop Progress Log

Started: 2026-03-28
Feature: canvas-tutor

## Codebase Patterns

- Next.js app lives in `app/`
- For AI tool streaming routes, use `streamText(...).toDataStreamResponse()` with `toolCallStreaming: true`; plain text streams drop tool events, and `maxSteps` only chains when tools return lightweight execute acknowledgements
- Excalidraw must be dynamically imported with `{ ssr: false }`
- Use `convertToExcalidrawElements()` with skeleton objects for programmatic drawing
- Import Excalidraw types from package export paths (`@excalidraw/excalidraw/types`, `@excalidraw/excalidraw/data/transform`)
- When AI adds scene elements, merge with `api.getSceneElements()` first so existing student drawings are preserved
- Keep the canvas command queue as a pure injected executor (`executeCommand` + optional `sleep`) so behavior stays unit-testable
- Treat `SpeechSynthesis` as unreliable I/O: wrap utterances in a cancelable promise with timeout + sync-error handling so narration can never deadlock the queue
