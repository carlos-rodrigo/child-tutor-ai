## Codebase Patterns

- Next.js 16 lint config in this app rejects synchronous `setState` inside effects; derive render-only state from props/turn data and keep async state transitions inside handlers.
- App code lives under `app/` (Next.js app router project nested inside repo root).
- Keep tutor/canvas contracts centralized in `app/lib/tutor-types.ts`.
- Keep lesson content isolated from rendering so future topics can swap in cleanly.
- Maintain AI-SDK-compatible backend shape even when using fallbacks.
